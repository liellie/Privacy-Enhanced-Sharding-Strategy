# ShardChain 0.1.0

Research software accompanying *Privacy-Enhanced Sharding Strategy in Digital Asset Sharing Based on Organizational Affinity and Load Awareness*.

- Offline trace replay with fixed paper, smoke, frontier and adaptability profiles.
- Archived result tables and chain measurement inputs.
- Solidity protocol prototypes and optional Java integration services.
- Result comparison, checksum verification and publication checks.

See [reproduction](REPRODUCIBILITY.md), [implementation scope](IMPLEMENTATION_SCOPE.md) and [validation](VALIDATION.md).
